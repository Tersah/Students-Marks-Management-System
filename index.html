How this project demonstrates arrays

Each student is an object stored inside one JavaScript array.

push()

Adds a new student record to the end of the array.

filter()

Finds matching students and removes a record by ID.

reduce() / map()

Calculates the class average and derives the highest mark.

Grade scale used in this demo: A = 80–100, B = 70–79, C = 60–69, D = 50–59, F = below 50. Change the thresholds in getGrade() if your school uses another scale.
